# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-15

### Added
- Initial public release of mcp-server-plaid
- Mock financial data generation tool
- Plaid documentation search functionality
- Sandbox access token retrieval
- Webhook simulation for testing
- Integration examples for Claude Desktop, Cursor, VS Code, and Zed
- Comprehensive documentation and setup guides
- MIT License

### Features
- **get_mock_data_prompt**: Generate customized mock financial data for testing
- **search_documentation**: Search Plaid documentation for API information
- **get_sandbox_access_token**: Obtain sandbox environment access tokens
- **simulate_webhook**: Test webhook handling with simulated events
